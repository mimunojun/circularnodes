# circularnodes

正方形グリッドと、それに内接する正円で分割された領域を塗ることで作字を行うツール。

**<https://mimunojun.github.io/circularnodes/>** で使えます。

> このリポジトリはコントリビュートを受け付けていません（[CONTRIBUTING.md](./CONTRIBUTING.md)）。

## 開発

```sh
npm install
npm run dev        # 開発サーバ
npm run build      # 型チェック + ビルド
npm run typecheck  # 型チェックのみ
```

## 操作（p0.1）

画面上部のメニューバー（ファイル / 編集 / 表示）から全機能を実行できる。ショートカットは修飾キーを伴わない単独キー。

| 操作 | 内容 |
| --- | --- |
| ドラッグ | 領域を塗る。塗り済みの領域から始めた場合はそのストロークは消去になる |
| `N` | 新規作成（サイズを指定して全消去） |
| `G` | グリッド線・内接円の表示切替 |
| `P` | PNG 書き出し（ガイド無し・背景透過） |
| `S` | SVG 書き出し（ガイド無し・背景透過） |
| `Esc` | 開いているメニューを閉じる |
| `⌘` + ホイール | 表示倍率を変える（25%〜400%） |
| `Space` + ドラッグ | 表示位置を動かす（押している間は描画しない） |

キャンバスサイズ（横 × 縦のセル数、既定 8 × 8、最大 100 × 100）は「編集 > キャンバスサイズを変更…」から変更する。領域を分ける曲線の形は「編集 > ノード形状を変更…」から 0〜1 の値で変えられる（0 = 四芒星、0.25 = 菱形、0.5 = 正円（既定）、1 = 角丸正方形）。ダイアログではセル 1 つのプレビューが操作に追従し、スライダーは 0.25（菱形）と 0.5（正円）で吸着する（目印つき）。表示倍率は画面下部のステータスバーの「-」「+」でも変えられる。ポインタが乗っている領域は赤い輪郭で示され、「表示 > ハイライト表示」で切り替えられる。セルの辺長と配色は `src/config.ts` の定数で変更する。
