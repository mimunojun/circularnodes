## 3. グリッドと領域のモデル

本アプリケーションの操作対象は、概要仕様書 3.1 で定義したグリッドが生成する**領域**である。以降の機能はすべてこのモデルを前提とする。

### 3.1 グリッドの構成

| グリッド | 定義 |
| --- | --- |
| 正方形グリッド | 辺長 `cellSize` の正方形セルを `columns` × `rows` 個並べた格子 |
| ノードグリッド | 各正方形セルの内側に置かれる閉曲線。既定は内接する正円 |

ノードグリッドは独立した格子ではなく、正方形グリッドから一意に導出される。その曲線の形は**ノード形状**（F-13）というパラメータ 1 つで決まり、既定値では内接円になる。どの値でも曲線はセルの 4 辺の中点を通るため、グリッドとしての接続性は変わらない。

したがってユーザが設定するのは、正方形グリッドのパラメータとノード形状のみである。

### 3.2 セル内の領域分割

ノードグリッドの曲線は正方形の各辺の中点を通るため、1 セルは次の 5 領域に分割される（図は既定の正円の場合）。

```
+--------+--------+     ┌─────────────┐
|  NW    |   NE   |     │ ╲    C    ╱ │   C  : 円の内側
|    ╲__/ \__/    |     │  ╲_______╱  │   NW : 左上の隅
|    /   C   \    |     │  │       │  │   NE : 右上の隅
|    \__    __/   |     │  ╱‾‾‾‾‾‾‾╲  │   SW : 左下の隅
|  SW   \  /  SE  |     │ ╱         ╲ │   SE : 右下の隅
+--------+--------+     └─────────────┘
```

| 領域種別 | 個数 / セル | 形状 |
| --- | --- | --- |
| 中心領域 (`C`) | 1 | ノードグリッドの曲線に囲まれた図形（既定では正円） |
| 隅領域 (`NW` / `NE` / `SW` / `SE`) | 4 | 正方形の隅とその曲線で囲まれた図形 |

- 1 セルあたりの領域数は 5、グリッド全体では `columns × rows × 5` である。ノード形状（F-13）を変えても**この分割数と領域の識別子は変わらない**。
- 隅領域は辺の中点でのみ他の隅領域と接するため、互いに独立した領域として扱う。
- TODO: 円領域をさらに分割する必要があるか（例：上下半円・四分円を個別に塗り分けたいケース）を決めること。参考字形では円は常に全体が塗られているように見えるため、v0.1 では分割しない方針とする。

### 3.3 領域の状態

| 状態 | 説明 | 表示 |
| --- | --- | --- |
| 未描画 | 初期状態 | 背景色 |
| 描画済み | ユーザが塗った状態 | 前景色 |

| （選択） | TODO: 選択という概念を持つか |  TODO |

## 8. F-04 グリッド設定

### 8.1 設定項目

| 項目 | 既定値 | 範囲 | 変更手段 | 説明 |
| --- | --- | --- | --- | --- |
| `columns` | 8 | 1〜32 | キャンバスサイズ変更ダイアログ（8.2） | 横方向のセル数 |
| `rows` | 8 | 1〜32 | 同上 | 縦方向のセル数 |
| `cellSize` | 48 | TODO | TODO（UI からは変更できない） | 正方形セルの辺長 |
| グリッド線の表示 | 表示 | 表示 / 非表示 | メニュー・`G`（F-08） | — |

キャンバスサイズは `columns` × `rows`（m × n）のセル数で指定する。ピクセル寸法は `columns × cellSize` × `rows × cellSize` として導出され、直接は指定しない。

上限を 32 としているのは、ズーム・パンを持たない現状では、これを超えるとキャンバスが画面に収まらなくなるためである。ズームの導入時に見直す。

`cellSize` は表示上のスケールではなく字形の設計単位として扱うか、単なる表示倍率として扱うか: TODO。

### 8.2 キャンバスサイズ変更ダイアログ

#### 8.2.1 表示のきっかけ

| きっかけ | 初期値 | 決定時の挙動 |
| --- | --- | --- |
| メニュー「編集 > キャンバスサイズを変更…」 | 現在のサイズ | サイズのみ変更し、描画は 8.3 に従って引き継ぐ |
| メニュー「ファイル > 新規作成」（`N`） | 既定サイズ 8 × 8 | 指定サイズの空のキャンバスにする（全消去） |

どちらも決定した時点で即座に適用する。適用のための追加操作（「反映」ボタン等）は設けない。

#### 8.2.2 構成

```
+-------------------------------------+
|  キャンバスサイズ                     |
|                                     |
|    横 [  8 ]  ×  縦 [  8 ]          |
|    1 〜 32 のセル数で指定します        |
|                                     |
|            [キャンセル]  [ 決定 ]     |
+-------------------------------------+
```

- モーダルとして表示し、開いている間は背後のキャンバスを操作できない
- 横（`columns`）と縦（`rows`）を独立した数値入力で受け取る

#### 8.2.3 入力の検証

| 入力 | 挙動 |
| --- | --- |
| 範囲内の整数 | 「決定」を押せる |
| 範囲外・空・整数でない | 「決定」を押せない。範囲を示す説明を出す |

#### 8.2.4 閉じる操作

| 操作 | 挙動 |
| --- | --- |
| 決定 | 適用して閉じる |
| キャンセル / `Esc` | 適用せずに閉じる |

「新規作成」から開いた場合、このダイアログのキャンセルが破棄の取り消しを兼ねる（別途の確認ダイアログは出さない）。

### 8.3 設定変更時の既存データの扱い

| 変更 | 挙動 |
| --- | --- |
| `cellSize` の変更 | 領域の状態は保持する（分割構造が変わらないため） |
| `columns` / `rows` の拡大 | 既存の領域は保持し、追加分は未描画とする |
| `columns` / `rows` の縮小 | 範囲外になる領域の描画は失われる。失われる描画があるときは、ダイアログ上でその旨を警告する |
| 新規作成 | サイズにかかわらず全領域を未描画にする |

領域は `{col, row, kind}` で識別され `cellSize` に依存しないため、保持できるのは新旧のセル範囲が重なる部分である。Undo による復元は F-05 の導入後に検討する。

## 13. F-09 メニューバー

### 13.1 目的

各機能への入口を 1 か所にまとめ、あわせてショートカットを提示する。ショートカットを知らないユーザでも全機能に到達できる状態にする。

### 13.2 配置

画面最上部に固定表示する。OS のメニューバーに倣い、次の性質を持つ。

- 画面幅いっぱいに広がる
- 常に最前面にあり、キャンバスの内容に隠れない
- 高さは固定

### 13.3 メニュー構成

| メニュー | 項目 | 下位項目 | 対応機能 | ショートカット |
| --- | --- | --- | --- | --- |
| ファイル | 新規作成 | — | F-03（全消去）/ F-04 | `N` |
| ファイル | 書き出し | PNG | F-07 | `P` |
| ファイル | 書き出し | SVG | F-07 | `S` |
| 編集 | キャンバスサイズを変更… | — | F-04 | なし |
| 編集 | ノード形状を変更… | — | F-13 | なし |
| 表示 | ガイド表示 | — | F-08 | `G` |
| 表示 | ハイライト表示 | — | F-12 | なし |

メニューの並びは「ファイル」「編集」「表示」の順とする。ズーム（F-10）はステータスバーから操作するため、メニューには置かない。

- 「書き出し」は下位メニューを持ち、それ自体は実行を伴わない
- 「ガイド表示」はトグル項目であり、有効時は項目の左端にチェックを表示する
- ラベル末尾の `…` は、選んでも即座には実行されず、ダイアログで入力を求めることを示す
- ショートカットを持たない項目は、ショートカットの区画を空にする（13.4）
- 項目の追加時は、対応する機能 ID を本表に記載すること

### 13.4 項目の表示

各項目は次の 3 つの区画を持つ。

```
+---------------------------------------------+
| ✓ | ガイド表示                          G   |
+---------------------------------------------+
  ^   ^                                    ^
  |   |                                    +-- ショートカット（右詰め・薄い色）
  |   +-- ラベル（左詰め）
  +-- チェック（トグル項目のみ）
```

- ショートカットは項目の右端に右詰めで配置し、ラベルより薄い色で表示する
- ショートカットを持たない項目は、その区画を空のままにする（ラベルの位置は揃える）
- 下位メニューを持つ項目は、ショートカットの代わりに右端に `▸` を表示する

### 13.5 開閉の挙動

| 操作 | 挙動 |
| --- | --- |
| メニュー名をクリック | そのメニューを開く。既に開いていれば閉じる |
| メニューを開いた状態で別のメニュー名にポインタを乗せる | 開くメニューをそちらへ切り替える |
| 下位メニューを持つ項目にポインタを乗せる | 下位メニューを開く |
| 項目を選ぶ | その機能を実行し、メニューを閉じる |
| メニューの外をクリック | 閉じる |
| `Esc` | 閉じる |

矢印キーによる項目間の移動は TODO（p0.1 では実装しない）。

### 13.6 ショートカットの表記

本アプリのショートカットは修飾キーを伴わない単独キーとする（[13.7](#137-修飾キーを使わない理由) 参照）。メニュー上の表記も修飾キーを付けず、`N` のように大文字 1 文字で示す。

### 13.7 修飾キーを使わない理由

`⌘N` / `⌘S` などの標準的な組み合わせは、ブラウザ上では OS・ブラウザ側の動作（新規ウィンドウ、ページの保存）に割り当て済みであり、横取りするとユーザの期待を壊す。本アプリはテキスト入力欄を持たないため、単独キーを割り当てても入力と衝突しない。

## 14. F-10 ズーム

### 14.1 目的

細部を確認しながら描く場合と、字形全体を見る場合とで必要な表示倍率が異なるため、表示倍率を変更できるようにする。

ズームは**表示だけ**を変える。グリッドの行数・列数（F-04）、セルの辺長、領域の状態、書き出し結果のいずれも変化しない。

### 14.2 倍率の範囲

| 項目 | 値 |
| --- | --- |
| 既定 | 100% |
| 下限 | 25% |
| 上限 | 400% |

範囲外になる操作は、下限・上限で頭打ちにする（操作自体は無効にしない）。

### 14.3 操作方法

| 操作 | 入力 | 挙動 |
| --- | --- | --- |
| 連続的な変更 | `⌘` + ホイール | ホイールの移動量に応じて滑らかに変える。ブラウザ自体のページズームは行わせない |
| 段階的な拡大 | ステータスバーの「+」ボタン | 次の段階へ上げる |
| 段階的な縮小 | ステータスバーの「-」ボタン | 前の段階へ下げる |

ボタンが用いる段階は 25% / 50% / 75% / 100% / 150% / 200% / 300% / 400% とする。段階の途中の倍率から押した場合は、その方向の直近の段階へ移動する。

`⌘` + ホイールは、ブラウザのページ全体の拡大縮小に割り当てられている。キャンバスの倍率だけを変えるため、この入力に対するブラウザ既定の動作は抑止する。トラックパッドのピンチ操作も同じ入力として扱う。

ショートカットキーは割り当てない。

### 14.4 ズームの中心

`⌘` + ホイールでは、**ポインタの下にある位置が動かないように**表示を調整する。ボタン操作ではステージの中心を保つ。

ポインタがステージの外（メニューバーやステータスバーの上）にある場合も倍率は変わる。この場合はステージの縁のうちポインタに最も近い点を基準とする。

### 14.5 ステータスバー

画面最下部に固定表示する。

```
+--------------------------------------------------+
| ドラッグ: 領域を塗る / …            [-] [+] 100%  |
+--------------------------------------------------+
```

| 位置 | 内容 |
| --- | --- |
| 左 | 操作の説明（ポインタ操作の説明。メニューに現れない操作を補う） |
| 右端 | 現在の倍率。整数のパーセントで表示する |
| 倍率の左 | 「-」ボタン、「+」ボタンの順に並べる |

- ボタンのラベルは「-」「+」のみとし、他の文字や記号を添えない
- 下限・上限に達している側のボタンは押せない状態にする

### 14.6 描画品質

拡大時もグリッドと字形の輪郭は滑らかに保つ。拡大後の見た目の解像度に合わせて描画するためであり、拡大済みの画像を引き伸ばす方式は採らない。

ただし、グリッドの大きさと倍率の組み合わせによっては描画先が過大になるため、描画解像度には上限を設ける。上限を超えた場合はその範囲で描画し、超過分は引き伸ばしで補う。

ガイド線の太さは倍率によらず一定に保つ。

## 15. F-11 パン

### 15.1 目的

拡大してキャンバスがステージに収まらなくなったとき、見る位置を移動できるようにする。

パンは**表示位置だけ**を変える。グリッド、領域の状態、倍率のいずれも変化しない。

### 15.2 操作方法

| 操作 | 入力 | 挙動 |
| --- | --- | --- |
| パン | `Space` を押しながらドラッグ | ポインタの移動量だけ表示位置を動かす |
| スクロール | ホイール、トラックパッドのスクロール | ステージのスクロールとして働く |

- `Space` を押している間は**描画・消去を行わない**。パンが描画より優先される
- `Space` を押している間、ブラウザ既定のスペースキーによるスクロールは抑止する
- ドラッグ中に `Space` を離した場合、その時点でパンを終える
- キャンバスがステージに収まっている場合、動かす余地がないため見た目は変わらない

### 15.3 ポインタの形

| 状態 | 形 |
| --- | --- |
| 通常 | 十字（描画できることを示す） |
| `Space` を押している | 開いた手 |
| `Space` + ドラッグ中 | 握った手 |

### 15.4 パンの範囲

ステージのスクロール範囲を超えては動かない。キャンバスの端まで表示したところで止まる。

## 16. F-12 ハイライト表示

### 16.1 目的

1 セルが 5 領域に分かれており、隅領域は円との接点付近で細くなる（3.2）。どの領域が対象になるかを押す前に分かるようにする。

### 16.2 表示

ポインタが乗っている領域の輪郭を、他の表示と区別できる強調色で描く。

| 項目 | 内容 |
| --- | --- |
| 形 | 対象の領域の輪郭そのもの（円領域なら円、隅領域なら辺と円弧で囲まれた形） |
| 色 | 赤。グリッド線・字形のいずれとも紛れない色とする |
| 線幅 | グリッド線より少しだけ太くする |
| 重なり | 他のすべての表示より前面に描く |

線幅は倍率によらず一定に保つ（14.6 のガイド線と同じ扱い）。

### 16.3 表示する条件

| 状況 | 挙動 |
| --- | --- |
| ポインタがキャンバス上の領域に乗っている | その領域を強調する |
| ポインタがキャンバスの外にある | 強調しない |
| ドラッグ中 | ポインタが移る領域に追従して強調する |
| パン中（`Space` を押している） | 強調しない。描画の対象を示すものであり、パン中は描画しないため |

強調は**表示だけ**を変える。領域の状態にも、書き出し結果にも影響しない。

### 16.4 表示の切替

メニュー「表示 > ハイライト表示」で切り替える。既定は表示。

グリッド線の表示（F-08）とは**独立して**切り替わる。一方を消してももう一方は影響を受けない。

ショートカットキーは割り当てない。

## 17. F-13 ノード形状

### 17.1 目的

セルを 5 領域に分ける曲線（ノードグリッド、3.1）の形を、菱形から正円を経て正方形まで連続的に変えられるようにする。字体の性格を決める最上位のパラメータであり、**ドキュメントの属性**として保持する。

### 17.2 定義

セル内の座標を中心基準で正規化し、`u, v ∈ [-1, 1]` とする（`u = ±1` がセルの左右辺、`v = ±1` が上下辺）。中心領域は次の式で定める。

```
|u|^p + |v|^p ≤ 1
```

これは L^p ノルムの単位球（スーパー楕円 / Lamé 曲線）である。指数 `p` は形状値 `t` から次で求める。

```
p = 1 / (1 - t)
```

| `t` | `p` | 形 |
| --- | --- | --- |
| -0.5 | 2/3 | アステロイド（凹んだ四芒星） |
| 0 | 1 | 辺の中点を頂点とする 45 度の正方形 |
| 0.5 | 2 | **正円（既定）** |
| 0.625 | 8/3 | 角の丸い正方形（上限） |
| （1） | ∞ | セルの正方形そのもの。隅領域が消滅するため採らない |

この対応では、曲線が対角線を横切る位置（中心から角までの比）が `2^(t-1)` となり、`t` に対して等比で進む。

### 17.3 この定義を採る理由

- **どの `t` でも曲線は 4 辺の中点を通る**。領域の分割数・識別子・隣接関係が変わらないため、`t` を変えても**既存の描画データがそのまま有効**である
- 内外判定が `|u|^p + |v|^p ≤ 1` の 1 式で済み、既定の正円の判定（`u² + v² ≤ 1`）をそのまま一般化した形になる
- `t > 0` では中点における接線が辺と平行になり、隣接セルの中心領域どうしが接線連続でつながる。`t = 0` では中点が 45 度の角、`t < 0` では中点が尖点（カスプ）になり、字体の性格が切り替わる

### 17.4 表示上の値

ユーザに見せる値は **0 〜 1** とし、**正円をちょうど中央の 0.5 に置く**。正円は既定値であり、この値を基準に上下どちらへ動かしたかが読み取れるようにするためである。

下限から正円まで、正円から上限までを、それぞれ前半・後半に等分して割り当てる。

| 表示値 | `t` | 形 |
| --- | --- | --- |
| 0 | -0.5 | アステロイド（下限） |
| 0.25 | 0 | 45 度の正方形 |
| **0.5** | **0.5** | **正円（既定）** |
| 1 | 0.625 | 上限 |

```
表示値 ≤ 0.5 : t = 下限 + (表示値 / 0.5) × (正円の t - 下限)
表示値 > 0.5 : t = 正円の t + ((表示値 - 0.5) / 0.5) × (上限 - 正円の t)
```

前半は `t` が 1.0 ぶん、後半は 0.125 ぶんを受け持つため、**前半と後半で `t` の進み方が 8 倍異なる**。これは意図した性質である。後半は隅領域が細くなっていく領域（17.6）であり、細かく詰めたいのに対し、前半は形が大きく変わる領域で粗く動かせれば足りる。

刻みは 0.001 とする。下限・上限の根拠は 17.6 に示す。

この割り当てでは、厳密に描ける 2 つの値（17.7）がどちらも刻みの上にちょうど乗る（0.25 → `t = 0`、0.5 → `t = 0.5`）。

### 17.5 変更方法

メニュー「編集 > ノード形状を変更…」のダイアログで変更する。ショートカットキーは割り当てない。

| 項目 | 内容 |
| --- | --- |
| 入力 | スライダーと数値入力。どちらを操作してももう一方に反映する |
| 範囲 | 0 〜 1、0.001 刻み |
| スライダーの吸着 | ドラッグ中、厳密に描ける値（0.25 / 0.5）の近くでその値へ吸着する。つまみも吸着後の位置に表示する |
| 吸着位置の目印 | スライダー上の 0.25 / 0.5 に目印を表示する |
| プレビュー（ダイアログ内） | セル 1 つを切り出した図を常時表示し、操作に追従させる |
| プレビュー（キャンバス） | 操作中は**即座にキャンバスへ反映**する |
| 決定 | その値で確定する |
| キャンセル / `Esc` | 開いたときの値に戻す |

スライダーの吸着は、よく使う 2 つの値（45 度の正方形・正円）をドラッグだけで正確に選べるようにするためである。

- 吸着が働く範囲は**スライダー上の距離**（両側に約 8px）で決める。値で決めると、スライダーの幅によって効き方が変わってしまうため
- 吸着している間は**つまみもその位置に描く**。値だけ吸着してつまみがポインタに追従すると、吸着していることが分からない
- **数値入力には効かない**。吸着範囲の中の値も、数値を打てば選べる
- **ドラッグ中だけ働く**。常時効かせると、矢印キーでの微調整が吸着範囲から出られなくなる

形は数値から想像しにくいため、2 段階のプレビューを置く。ダイアログ内の図は 1 セルの分割そのものを示し、キャンバスへの即時反映は字形全体への影響を示す。

#### ダイアログ内プレビュー

正方形セルを 1 つだけ切り出して描く。

| 要素 | 表示 |
| --- | --- |
| セルの外形 | 正方形の枠線 |
| 中心領域 | 塗りつぶし |
| 隅領域 | 塗らない（枠と中心領域の差として見える） |

セル 1 つに絞るのは、変わるのがセル内の分割だけだからである。

### 17.6 範囲の根拠

セル全体を 100% としたときの各領域の面積は次のとおり。

| `t` | 表示 | 中心領域 | 隅 1 つ | 48px セルでの隅 |
| --- | --- | --- | --- | --- |
| -0.5 | -80% | 29.5% | 17.6% | 405 px² |
| 0 | 0% | 50% | 12.5% | 288 px² |
| 0.5 | 80% | 78.5% | 5.4% | 124 px² |
| 0.625 | 100% | 86.0% | 3.5% | 81 px² |

- **上限**: これより大きいと隅領域が小さくなりすぎ、ポインタで狙えなくなる
- **下限**: これより小さいと中心領域の先端が細くなりすぎる（上限における隅領域と同じ問題が、中心領域側に現れる）

### 17.7 描画上の扱い

`t` が既定値（正円）のときは円・円弧として厳密に描く。`t = 0` のときは直線で描く。それ以外は 3 次ベジェ近似とする。スーパー楕円は円弧でも楕円弧でも表せないためである。

よく使う 2 つの値では書き出した SVG が厳密な円弧・直線のまま保たれる。

近似の分割数は四分曲線あたり 4 本とする。48px セルでの実測で、範囲全体にわたり最大誤差 0.015px（セル辺長の 0.03%）に収まる。
