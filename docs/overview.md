## 2. 背景・目的

字体の1つのトレンドとして、「ピクセル字体+円形」というものがある。正方形グリッドと、それに内接する正円のみで描かれる字体である。
このトレンドに則って作字をする場合、Illustratorなどでグリッドと正円に対応する要素をそれぞれ準備して設計する必要があるが、これは手間がかかる。
そこで、元からそのグリッドが用意され、ユーザはそのグリッドに対して描画するようなデザインツールとして、本アプリケーションを提案する。

### 3.1 コアコンセプト

- **グリッド**: 正方形グリッドとノードグリッドの2つから構成される。
  - 正方形グリッド: 描画の土台となる格子。ユーザは辺長を自由に設定できる。
  - ノードグリッド: 正方形グリッドを基準に、各正方形の内側に閉曲線を定義し、その曲線で正方形グリッドの領域を分割する。既定では各正方形に内接する円であり、**ノード形状**というパラメータ1つで、辺の中点を結ぶ菱形から角の丸い正方形まで連続的に変えられる（[機能仕様書](./functional-spec.md) 17 章）。曲線はどの値でも辺の中点を通るため、分割の構造は変わらない。
- **領域**: グリッドを構成し、ユーザが描画対象として選択する単位。領域は上記グリッドで分割された各領域である。
- **描画**: 領域を塗る／消すという操作の反復によって字形を構成する。

### 3.2 対象とする字体

正方形グリッドと、それに内接する正円だけで構成される字体。文字はセルを単位として組まれ、円と、円で切り取られた正方形の隅の組み合わせで字形をつくる。曲線はすべて同じ半径の円弧であり、隣接するセルの円がつながることで、太さの一定したストロークになる。
